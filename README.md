# КТ#2. Express REST API

## Задание

Разработать REST API для управления каталогом товаров. API должно поддерживать полный CRUD, валидацию входных данных через, логирование запросов и загрузку изображений товаров.

### Маршруты

Метод | URL | Описание 
--- | --- | ---
`GET` | `/api/products` | Список товаров с фильтрацией и пагинацией
`GET` | `/api/products/:id` | Один товар
`POST` | `/api/products` | Создать товар
`PUT` | `/api/products/:id` | Заменить товар полностью
`PATCH` | `/api/products/:id` | Обновить частично
`DELETE` | `/api/products/:id` | Удалить товар
`POST` | `/api/products/:id/image` | Загрузить изображение товара

### Поля товара

Поле | Тип | Ограничения
--- | --- | ---
`id` | `number` | Генерируется автоматически
`name` | `string` | Обязательное, 2–100 символов
`price` | `number` | Обязательное, больше 0
`category` | `string` | Обязательное, одно из: *electronics*, *clothing*, *food*, *other*
`stock` | `number` | Целое, минимум 0, по умолчанию 0
`description` | `string` | Опциональное, максимум 500 символов
`imageUrl` | `string` | Опциональное, заполняется при загрузке
`createdAt` | `string` | Генерируется автоматически
