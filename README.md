## Задание

Разработать REST API для управления каталогом товаров. API должно поддерживать полный CRUD, валидацию входных данных, логирование запросов и загрузку изображений товаров.

### Структура проекта

Маршруты:

Метод | URL | Описание 
GET | /api/products | Список товаров с фильтрацией и пагинацией
GET | /api/products/:id | Один товар
POST | /api/products | Создать товар
PUT | /api/products/:id | Заменить товар полностью
PATCH | /api/products/:id | Обновить частично
DELETE | /api/products/:id | Удалить товар
POST | /api/products/:id/image | Загрузить изображение товара

Поля товара:

ПолеТипОграничения
idnumberГенерируется автоматическиname
stringОбязательное, 2–100 символов
pricenumberОбязательное, больше 0
categorystringОбязательное, одно из: electronics, clothing, food, other
stocknumberЦелое, минимум 0, по умолчанию 0
descriptionstringОпциональное, максимум 500 символов
imageUrlstringОпциональное, заполняется при загрузке
createdAtstringГенерируется автоматически

Требования к middleware:

— кастомный логгер выводит метод, URL, статус и время выполнения каждого запроса 

— валидация через Joi, при ошибках возвращается 400 с массивом details 

— загрузка изображений через Multer: только JPEG и PNG, максимум 2 МБ 

— error handler перехватывает все необработанные ошибки

Требования к GET /api/products:

— query-параметр category фильтрует по категории 

— query-параметры minPrice и maxPrice фильтруют по цене 

— query-параметры page и limit реализуют пагинацию 

— ответ содержит поля data, total, page, limit
